# Ren'Py / Godot common subset — specification v0.1

[Version française](SPEC-sous-ensemble-renpy.md)

## 1. Principle

- **Ren'Py is the reference.** Every script in the subset is a valid Ren'Py script. It must play out the same way in the Godot player: same lines, same choices, same variables, same order.
- **Shared scripts live in `game/story/`.** They are generated from the scene sheets in `contenu/` by `tools/fiches.py` (see [contenu/README.md](contenu/README.md)), which only produces this subset: do not edit them by hand. Godot only reads this folder. Ren'Py-specific code (`gui.rpy`, `screens.rpy`, `options.rpy`, gallery screens, etc.) stays in `game/`, outside `story/`.
- **Anything outside the subset is an error.** The Godot compiler reports it as `file:line`, so it also works as a linter for writers.

## 3. Supported statements

### Top level (no indentation)

| Statement | Syntax | Notes |
|---|---|---|
| Character | `define lena = Character(_("Léna"), color="#c8a2ff")` | The name is a string, or `_("…")` to have it translated. Accepted arguments: `color` (or `who_color`), `what_color`. |
| Constant | `define x = expression` | Re-evaluated on every load, as in Ren'Py. |
| Variable | `default x = expression` | Saved. A variable added later is initialised when a save is loaded. |
| Image | `image lena triste = "images/other_name.png"` | Optional: files in `game/images/` are declared automatically. |
| Label | `label name:` | At the end of the block, execution continues with the next label of the same file. The end of a file acts as `return`. |

### Inside a label

| Statement | Syntax | Notes |
|---|---|---|
| Narration | `"Text"` | May end with `id identifier`, like a line. |
| Line | `lena "Text"` or `"Any name" "Text"`, optionally followed by `id identifier` | The `id` links the line to its translations (section 6) and must be unique. |
| Background | `scene rue_nuit [with dissolve]` | `scene` alone clears the screen. Removes every character. |
| Character | `show lena sourire [at right] [with dissolve]` | Positions: `left`, `center`, `right`, `truecenter`. Without `at`, keeps the previous position of the same tag (`center` by default). |
| Hide | `hide lena [with dissolve]` | |
| Transition | `with dissolve` | Transitions: `dissolve`, `fade`, `None`. |
| Menu | see below | An optional line before the choices. A choice may have `if condition`. |
| Condition | `if` / `elif` / `else` | |
| Loop | `while condition:` | No `break` or `continue`. |
| Jump | `jump label`, `call label`, `return` | `return` without a value. |
| Assignment | `$ x = …`, `$ x += …`, `$ x -= …`, `$ x *= …` | |
| Video | `$ renpy.movie_cutscene("videos/scene.webm")` | See section 5. |
| Pause | `pause`, `pause 1.5`, `$ renpy.pause(1.5)` | `pause` alone waits for a click. |
| Audio | `play music "audio/theme.ogg" [fadein 1.0] [fadeout 1.0] [loop\|noloop]` | Channels: `music`, `sound`, `audio`. |
| Stop audio | `stop music [fadeout 1.0]` | |
| Misc | `pass`, `window show\|hide\|auto`, `# comment` | `window` is ignored by Godot. |

```renpy
menu:
    lena "Alors… tu restes un peu ?"

    "Lui faire confiance":
        $ relation_lena += 2
        jump ch01_sc03a

    "L'interroger sur la photo" if indice_photo:
        jump ch01_sc03b
```

A choice whose condition is false is not displayed. A menu with no visible choice is skipped, as in Ren'Py.

### Text

- `[variable]` inserts the value of a simple variable. `[[` produces a literal bracket.
- Tags converted to Godot BBCode: `{b}`, `{i}`, `{u}`, `{s}`, `{color=#hex}`. The others (`{w}`, `{p}`, `{size}`, etc.) are ignored by Godot.

## 4. Expressions

They are translated from Python to Godot's `Expression` class.

- **Allowed:** numbers, strings `"…"` or `'…'`, `True`, `False`, `None`, lists `[…]`, `+ - *`, comparisons, `and`, `or`, `not`, `in`, parentheses, the functions `min`, `max`, `abs`, `str`, `int`, `float`.
- **Forbidden:** `/`, `//` and `%` (results differ between Python and Godot), dotted access (`persistent.x`, `renpy.random…`), `is`, conditional expressions `a if c else b`, `lambda`, comprehensions.
- Every variable used must be declared with `default` or `define`, or assigned with `$`.

## 5. Media

- **Images:** `game/images/` (subfolders allowed), as PNG, JPG or WebP. The lowercase file name gives the image name; spaces separate the tag from the attributes, as in Ren'Py.
- **Videos:** the script references the `.webm`, which Ren'Py plays. Godot plays the `.ogv` (Ogg Theora) with the same name. `python3 tools/convertir_videos.py` generates missing or outdated `.ogv` files.
- **Audio:** prefer Ogg Vorbis `.ogg`, which both engines play. Godot does not play Opus.
- **Gallery:** `game/galerie.json`, generated from the `galerie` field of the scene sheets, lists the entries. Godot reads it in `engine/gallery.gd`, Ren'Py in `game/galerie.rpy`. Each entry is unlocked once its label has been reached (`renpy.seen_label` on the Ren'Py side). It shows either images one by one on a black background, or a video; a click moves to the next image or stops the video. Format:

```json
{"entrees": [
  {"titre": "La confiance de Léna", "label": "ch01_sc03a", "vignette": "lena rougit",
   "video": "videos/lena_scene_01.webm"},
  {"titre": "Le secret de Léna", "label": "ch01_sc03b", "vignette": "lena serieuse",
   "images": ["appartement_soir", "lena serieuse"]}
]}
```

The tests check that every label, image and video it mentions exists.

## 6. Translations

Ren'Py's translation system, restricted as follows; the Godot player reads the same files.

- **Languages:** `game/langues.json`, generated from the bible (`langues`), lists the language of the sheets and the translations: `{"source": {"code": "fr", "renpy": "french", "nom": "Français"}, "traductions": [{"code": "en", "renpy": "english", "nom": "English"}]}`. Ren'Py reads it in `game/langues.rpy`, Godot in `engine/langues.gd`.
- **Translated lines:** `game/tl/<language>/**/*.rpy`, generated by `tools/fiches.py`. A `translate <language> <id>:` block holds exactly one line (narration or character): the translation of the line that carries `id <id>`.

```renpy
translate english ch01_sc02_14e17bdd:

    # lena "Je ne pensais pas que tu viendrais."
    lena "I didn't think you'd come."
```

- **Texts:** `translate <language> strings:` blocks, with `old "…"` / `new "…"` pairs, translate character names (declared with `_()`), menu choices and gallery titles.
- **Ren'Py only:** `translate <language> python:` and `translate <language> style:` blocks only affect the Ren'Py interface, and Godot ignores them. Any other statement in `game/tl/<language>/` is an error in Godot.
- **Default language:** the language of the sheets is Ren'Py's default language (`config.default_language`). Its interface texts are translated in `game/tl/<language>/` (French is provided, taken from Ren'Py's own translations); in English, Ren'Py's interface texts are the originals. The Godot interface texts are in `engine/ui/traductions_interface.gd`.
- **Choosing a language:** Preferences → Language, in both engines. On first launch, the game uses the system language if it is available, otherwise the language of the sheets.
- A line or a text without a translation is shown in the original language.

## 7. Outside the subset

These remain reserved for Ren'Py files located outside `game/story/`:

- `python:` and `init python:` blocks;
- `screen`, `call screen`, `transform` and ATL, `style`, `nvl`, `voice`, `queue`, `layeredimage`, `for`;
- `translate` in `game/story/`: translations go to `game/tl/<language>/` (section 6);
- named menus, `set`;
- image attributes in dialogue lines (`lena sourire "…"`): use `show` before the line;
- `show … behind | zorder | onlayer | as`;
- multi-line strings;
- `renpy.*` except `movie_cutscene` and `pause`, as well as `persistent`.

## 8. Known differences in the Godot player

- **Saves:** the position is stored as "label + instruction number". Editing a label before the saved point can shift where the game resumes; Ren'Py is more tolerant.
- **Godot player features:** main menu, game menu, history (250 lines), rollback (128 interactions), skip limited to already-read text, auto-forward, 5 pages of 6 slots with thumbnails, quick save (F5 / F9), preferences and gallery.
- **Rollback:** it does not survive loading a save (Ren'Py keeps it in the save). There is no rollforward either.
- **Preferences missing in Godot:** "keep skipping after choices", accessibility. The auto-forward delay is computed more simply than in Ren'Py.
- **Already-read text:** a line is identified by its `id` when it has one (the same in every language), otherwise by its label, its speaker and its text. Editing it makes it "unread" again, as in Ren'Py.
- **Gallery:** Ren'Py adds it to the main menu (a "Gallery" button in `screens.rpy`, translated like the rest of the interface).
- **Changing language during a game:** Godot redisplays the current line or menu in the new language at once. Earlier lines stay in the history in the language they were shown in.
- **`with` on its own:** in Godot, transitions only apply on a `scene`, `show` or `hide` line. A standalone `with` line has no visual effect.
- **`show`:** the image name must exist as written. Godot does not resolve partial attributes the way Ren'Py does.
- **`fade`:** Godot fades in from black, while Ren'Py fades to black and back.
- **Sprites:** displayed at their native size, scaled down only if they are taller than the screen.

## 9. Commands

| Action | Command |
|---|---|
| Play (Godot) | `godot --path .`, or open `project.godot` in the editor and press F5 |
| Play in a language (Godot) | `godot --path . -- --langue=en` (this session only; the saved preference is unchanged) |
| Autoplay | `godot --path . -- --choices=1,0` (rank among the displayed choices) |
| Scripted UI run | `godot --path . -- --actions=start,advance,menu:history,back,quit` (actions listed in `_run_action`, `engine/vn_player.gd`) |
| Godot tests | `godot --headless --path . --script res://tests/run_tests.gd` |
| Route report | `godot --headless --path . --script res://tools/routes.gd` |
| Play (Ren'Py) | `$RENPY_SDK/renpy.sh .`, or from the launcher |
| Ren'Py lint | `$RENPY_SDK/renpy.sh . lint` |
| Ren'Py tests | `$RENPY_SDK/renpy.sh . test --overwrite-screenshots` (screenshots in `tests/screenshots/`) |
| Placeholder media | `.venv/bin/python tools/fiches.py provisoires` |
| Translation file | `.venv/bin/python tools/fiches.py traduire en` |
| Videos for Godot | `python3 tools/convertir_videos.py` |

**Ren'Py side (already done):** the interface was generated at 1920×1080 with the launcher's hidden command, then completed with `gui_images` (normal and "small phone" variant). The template `script.rpy`, which redefined `label start`, was removed. To regenerate it:

```sh
SDK=$RENPY_SDK
$SDK/renpy.sh $SDK/launcher generate_gui "$PWD" --width 1920 --height 1080 --accent "#b48cff" --template $SDK/gui --start
RENPY_VARIANT="small phone" $SDK/renpy.sh . gui_images
$SDK/renpy.sh . gui_images
rm game/script.rpy
```

In a Ren'Py test, `advance` also interrupts a playing video, like a player's click. The `video_seule` test therefore checks WebM playback without a simulated click.

- Ren'Py: `*.ogv` and `*.import` are excluded with `build.classify` (already set up in `game/options.rpy`).
